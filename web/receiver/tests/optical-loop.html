Optical loop: sender pixels → zxing-cpp → Rust receiver

The seam no unit test crosses. QR modules generated by the desktop sender (cargo run -p desktop-sender --example qr_fixture) are painted onto a canvas the way a screen would paint them, read back by the same pinned decimen-codec zxing-cpp build the receiver ships, and fed to the Rust WasmReceiver. Every fourth frame is missing, so completing means the fountain recovered the payload from a lossy optical read and both integrity checks agreed.

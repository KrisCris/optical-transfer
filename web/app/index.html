    Denser codes need a steadier, closer camera. Each code stays up a whole number of screen refreshes, so frames per second is a ceiling: 36 is four refreshes on a 144 Hz screen and two on a 60 Hz one, which runs at 30. A phone filming at 60 fps misses most codes shown for less than about 25 ms, which the Display line flags; faster rates are for a receiver capturing at 120, on a screen that refreshes fast enough (Safari holds pages to 60 Hz unless its “Prefer Page Rendering Updates near 60fps” feature flag is off).
    
        
    Colour stacks three codes in the red, green and blue channels. Cameras keep colour coarser than brightness, so the Colour preset uses larger modules (1465 bytes a layer) and still carries half again what Fast does; denser colour codes only read while the code fills most of the camera’s view. Wire v4 finishes from almost exactly the data sent and carries up to 128 MiB; choose v3 only for an upstream Decimen receiver, which reads neither v4 nor colour.
